# AI_PROMPT — ИИ-консультант в чате

## Как это работает

1. Посетитель пишет в чат.
2. Бэкенд (`app/backend/main.py`, `/api/chat`):
   - читает `app/data/system_prompt.txt`;
   - определяет тему сообщения (`detect_categories`) и подставляет в промт только нужные категории каталога: ноутбук → ~2–3 тыс. токенов, сборка ПК → до 15 позиций на каждую из 8 категорий (~9 тыс. токенов);
   - отправляет запрос в Yandex AI Studio (OpenAI-совместимый API).
3. Ответ возвращается посетителю.

**Модель видит только товары каталога** и обязана давать цены/ссылки строго из него.

## Модель и ключ (актуально)

Используется **Yandex AI Studio**, модель **DeepSeek 4 Flash** — дёшево, работает с РФ, не требует зарубежной карты.

Настройки в `/root/app/.env` на сервере:

| Параметр | Значение |
|---|---|
| `LLM_BASE_URL` | `https://ai.api.cloud.yandex.net/v1` |
| `LLM_AUTH` | `Api-Key` |
| `LLM_API_KEY` | ключ из кабинета Yandex Cloud (вводится только на сервере, никому не показывать) |
| `LLM_PROJECT` | id каталога Yandex Cloud (b1g...) |
| `LLM_MODEL` | `gpt://<id каталога>/deepseek-v4-flash/latest` |
| `LLM_BUILD_PER_CATEGORY` | `15` — сколько позиций каждой категории уходит в запрос про сборку |

После правки `.env`: `docker restart teking` (пересоздавать контейнер не нужно).

## Расходы

Лимит расхода задаётся в кабинете Yandex Cloud (Billing → Budgets). Смотрите потребление в разделе использования модели. Типичный диалог — единицы копеек; сборка ПК дороже, т.к. контекст ~9 тыс. токенов.

## Как редактировать поведение ИИ

Файл `app/data/system_prompt.txt` — обычный текст. После правки:

```bash
scp app/data/system_prompt.txt root@185.149.145.147:/root/app/data/
docker cp /root/app/data/system_prompt.txt teking:/app/data/system_prompt.txt
docker restart teking
```

Важные разделы промта:
- **АБСОЛЮТНЫЕ ПРАВИЛА** — не выдумывать цены/модели; каждая строка таблицы = одна позиция каталога, ссылка только из её поля `url` (это защита от ситуации «на все комплектующие одна ссылка на ленту»).
- **5.1 ПРАВИЛО ЦЕН И МАГАЗИНОВ** — сборка из самых дешёвых подходящих позиций из всех магазинов; вопрос про «один магазин» — только после выдачи.
- **Сценарий А** — обязательные уточняющие вопросы (монитор/разрешение, подсветка/внешний вид, задача, хранилище), альтернатива ноутбуком, нумерованные варианты сравнения.
- **ЧЕК-ЛИСТ СОВМЕСТИМОСТИ** — сокет, память, БП, длина GPU, высота кулера.

Важно: промт работает, только если у товаров заполнены технические поля (сокет, TDP, мощность БП и т.д.). Парсер их заполняет частично — при ручном добавлении товаров заполняйте по образцу.
