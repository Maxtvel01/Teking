# PARSER — парсер каталога

Файл: `app/scripts/parser_daily.py` (запускается НА КОМПЬЮТЕРЕ, не на сервере).

## Что делает

- Парсит **Ситилинк и DNS** (реальные цены, скидки, наличие, характеристики).
- Автоматически отбрасывает товары из чужих категорий (светодиодные ленты, кабели и пр.).
- На выходе: `catalog_daily.json` — его загружаете в админке сайта кнопкой импорта (заменяет каталог целиком).

## Порядок работы

1. На компьютере: `python app/scripts/parser_daily.py`
2. В консоли будет `[INFO] отброшено N товаров из чужих категорий` — так и должно быть.
3. Открываете админку сайта → импорт JSON → выбираете `catalog_daily.json`.

## Старый файл

`app/backend/parser_ozon_ym.py` — устарел (Ozon/ЯМ, не тестировался). Можно удалить из папки, на работу сайта не влияет.

- М.Видео, Регард, Ozon, ЯМ — требуют доработки экстракторов.
