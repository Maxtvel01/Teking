# DESIGN — дизайн сайта

Текущий стиль: «бордо» + анимации (обновлено 14–15.10.2026).

## Где живёт дизайн

- ВСЕ стили — `app/frontend/css/style.css` (переменные в `:root`).
- Тексты/структура — `app/frontend/index.html`.
- Логика чата и каталога — `app/frontend/js/app.js`.
- Анимации — `app/frontend/js/motion.js` + библиотеки в `app/frontend/js/vendor/`:
  GSAP (анимации), ScrollTrigger (появление при скролле), Lenis (плавный скролл страницы), tsParticles (частицы-точки в шапке). Все локальные, CDN не нужен.

## Палитра (`:root` в style.css)

```css
--bg: #2E272B;      /* общий фон (графит) */
--bg-deep: #241E21; /* фон секций */
--acc: #7A0D22;     /* ГЛАВНЫЙ акцент (бордо): кнопки, ссылки */
--acc-h: #A5102C;   /* акцент при наведении */
--txt: #F3EEEF;     /* текст */
--txt2: #AD9EA3;    /* вторичный текст */
```

## Структура главной (index.html, сверху вниз)

1. **Шапка** (фикс.): логотип, меню, кнопка «Написать в чат».
2. **Hero**: заголовок, с анимированными частицами (`#hero-particles`, canvas tsParticles).
3. **Окно чата**: шапка «онлайн» → **история сообщений** → индикатор печати → **поле ввода снизу** (как в мессенджере). Колесо мыши над чатом листает чат, не страницу.
4. «Как это работает» (схема), каталог с фильтрами, подвал.
